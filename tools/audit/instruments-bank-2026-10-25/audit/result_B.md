# Packet B: independent audit (gyros, AH, turn/slip, INS/IRS/FMS, compasses/DGI, EFIS, FD)

Auditor did not build this bank. References: `ref_instr_book05.txt` (R1), `ref_instr_oxford.txt` (R2). "OCR" = the item's `book_worked_text_ocr`.

**No WRONG_KEY found under the bank's own sign convention.** The most serious finding is the four signed gyro-drift items (GYRO|85 to 88). Both reference manuals use the opposite sign convention to the bank, and the stems do not say which convention applies. So if the site's notes teach the references' convention, those four keys are wrong.

## Spot checks that passed (evidence for the main traps)

- **Classic AH turning errors** (ATTITUDE\|3 d, ATTITUDE\|8 b, GYRO\|30 b, GYRO\|7 c, ATTITUDE\|2 a). R2: "Turning through 90°: Under-reads bank angle, Pitch error indicating a climb / 180°: Bank angle correct, climb / 270°: Over-reads bank angle, climb / 360°: correct". GYRO\|42 nose-up on acceleration also passes. R2: "a false nose-up, right wing down... indication".
- **Compass acceleration errors.** R2: "Deceleration on 090°M (NH)... anticlockwise... over-reading", which supports COMPASS\|53 c. The nearer/further-pole rule supports COMPASS\|24, 59, 67, 3, 30, 46 and 12.
- **Compass turning errors.** R2: through the further pole the compass is "lively... roll out late". That supports COMPASS\|34 a (115) and COMPASS\|44 d (245).
- **Rate-1 bank.** Exact: tan(AOB) = 0.05236 rad/s × TAS(m/s) / 9.81. Results: 150 kt 22.4° (a ✓), 120 kt 18.2° (c ✓), 250 kt 34.5° (a 32 nearest ✓), 300 kt 39.5° (c 37 nearest ✓), 27° gives 185.6 kt (a 200 nearest ✓), 125 kt 18.9° (c 19.5 nearest ✓).
- **RMI stuck rose.** 270 − 075 = 195 ✓ and 120 − 080 = 40 ✓.
- **Radio altitude display.** EFIS\|9 c and EFIS\|16 b match R2: "Below 1000 ft the display automatically changes to a white circular scale... diminishes in length in an anticlockwise direction".
- **INS error classes.** INS\|16 c matches R2 "Bounded / Unbounded / Inherent errors".
- **Cost index.** CI 0 gives maximum range (R2 "Entering a cost index of 'ZERO' provides economy speeds representing a maximum range"). Supports INS\|42 a.
