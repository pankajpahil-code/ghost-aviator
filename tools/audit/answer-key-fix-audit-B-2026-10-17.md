## Discrepancies / concerns (exact quotes)

To reach 134 you would need a factor of ≈1.252 (e.g. 1.25 × 107 = 133.75), not the 1.23 used. The nearest listed option to 131.6/132.2 is still **(c) 134**, so the keyed answer is not undermined — but the printed equality is false. It was carried verbatim from the pre-fix text (archive `before`: *"[For the variant with 325/8000 ft: 1.23×(18+89)=134 NM]"*) and is mirrored in `lib/generated/oxford-radio-nav.ts` L2085. Consequently the report's fix-table row 9 / archive note *"both derivations now stated cleanly"* cannot be reproduced as written. Not edited (read-only audit); this should be folded into the open key-flip ruling.
2. **rnav-15 Q3 — minor precision.** Note: *"Raw echo time: 1290 / 12.36 = 104.3 NM → option (b)."* Exact quotient is 104.3689; 1-dp rounding gives 104.4 — the printed 104.3 is the option label (truncation). Substance (raw → option b; delay-corrected → option a) is correct; cosmetic only.
3. **ar-19 Q1 — doctrinal residual, not a fix error.** The keyed option A ("…and to help the judges") is not the doctrinally pure ICAO Annex 13 answer (its "sole objective … prevention" points to C). The page is now internally consistent and explicitly attributes A to the source key ("per textbook answer key" tag; "Textbook Answer: A."). Transparency achieved; flagged for the Captain only.
