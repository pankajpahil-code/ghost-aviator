# Met notes — diagrams to generate in Antigravity (Gemini / Nano Banana)

Textbook figures that exist were cropped and are already in the notes (121 of them). The topics below have
**no usable figure in the books**, so they are generated. Paste each prompt whole (clipboard, never type it).

## How to use (house rules — each one comes from a defect that already shipped)

1. Paste the **STYLE BLOCK** first, then the **figure prompt**, in one message.
2. Save as `D:\pk\met-figures\generated\<filename>.png` (the filename is given per prompt).
3. **Open every image at full size before using it.** Reject and re-prompt if you see: any title or banner,
   any text not on the label list, garbled letters, a logo or watermark, a number that differs from the prompt,
   or a physics error (arrow the wrong way, warm and cold swapped).
4. Captions are written in HTML, never inside the picture. Send the accepted files back and they are placed
   under the right heading, with alt text written from what the picture really shows.

## STYLE BLOCK (paste before every prompt)

> Clean educational illustration for student pilots. Realistic, rich colour, soft natural lighting, crisp edges, high
> resolution, 16:10 landscape. Plain white or very pale background. **Use ONLY the labels listed below, spelled exactly
> as listed, in a clear sans-serif font. NO title, NO banner, NO heading text, NO logo, NO watermark, NO author or
> website name, no extra words, no decorative text.** Arrows are solid and clearly pointed. Scientific accuracy matters
> more than decoration: follow every number and direction given.
