1. Introduction to Station Model

Definition: A station model is a standardised symbolic representation of surface weather observations plotted on a synoptic weather chart. Each symbol, number, and code occupies a fixed position relative to a central circle that represents the observation station.

Met stations worldwide make standardised surface observations and encode them using WMO codes. These are then plotted as station models on synoptic charts used by forecasters and pilots. Reading a station model is a core DGCA exam skill.

🎯 Exam Tip: The station model is always tested in DGCA exams — usually 3–5 questions per paper. Memorise parameter positions, ww codes, and cloud symbol tables.

4. Present Weather (ww) Code Tables

ww Code Ranges:
  • 00–19 — No precipitation at station at time of observation
  • 20–29 — Weather during last hour but NOT at time of observation
  • 30–39 — DS, SS or blowing SN at time of observation
  • 40–49 — Fog at time of observation
  • 50–59 — Drizzle at time of observation
  • 60–69 — Rain at time of observation
  • 70–79 — Solid precipitation (Snow etc.) at time of observation
  • 80–89 — Shower at time of observation
  • 90–99 — Thunderstorm with precipitation at time of observation

Pressure Decoding Rule

PPP = Last 3 digits of pressure in tenths of hPa
Rule: If PPP > 500 → prefix 9 (e.g., 996 → 999.6 hPa)
If PPP ≤ 500 → prefix 10 (e.g., 024 → 1002.4 hPa)

Example: PPP = 962 → 996.2 hPa (prefix 9)
Example: PPP = 024 → 1002.4 hPa (prefix 10)
Quick Rule: PPP > 500 → add 9 in front; PPP ≤ 500 → add 10 in front. Then divide the full 4-digit number by 10 to get hPa.

9. Practice Q&A

Based on the example station model: Wind 090/ω; TT=34, VV=●, Td=93, Nh=27, [circle=●], h/Nh=3/2, PPP=962, PP=15, ww=●, W₁W₂=…, 5×

Q1. The direction of surface wind is: (a) NW (b) NE (c) SE
✅ Correct Answer: (a) NW — Wind barb points from NW (330°)
❌ (b) NE and (c) SE are wrong — the barb tail indicates direction FROM which wind blows. 330° = NNW, closest to NW.
💡 Instructor's Note: Wind barb tail points TO the direction the wind blows FROM. 330° = NNW = closest to NW among options.
Q2. The range of wind speed is: (a) 20–25 kt (b) 16–22 kt (c) 18–22 kt
✅ Correct Answer: (b) 16–22 kt — One long barb = 10 kt, one short = 5 kt, so 15 kt is in 16–22 range
❌ (a) 20–25 and (c) 18–22 are wrong ranges for 15 kt.
💡 Each full barb = 10 kt; half barb = 5 kt; pennant = 50 kt. 15 kt = one full + one half.
Q3. The type of medium cloud is: (a) AC (b) AS (c) AC &AS
✅ Correct Answer: (c) AC & AS — CM code 7 = AC with AS or NS
❌ (a) AC alone is code 3 or 4; (b) AS alone is code 1 or 2.
💡 Read CM symbol carefully — "ZZ" type symbol on the station model indicates mixed AC/AS.
Q4. Low clouds are: (a) CU (b) SC (c) ST
✅ Correct Answer: (a) CU — CL code 1 = Fair weather Cumulus
❌ (b) SC = CL code 4 or 5; (c) ST = CL code 6 or 7.
💡 Fracto Stratus is also a possible low cloud in fog conditions — check the CL symbol carefully.
Q5. High clouds are: (a) CC (b) CI (c) CS
✅ Correct Answer: (b) CI — CH code 1 = Cirrus in filaments; the textbook example shows AS/NS for CM
❌ (a) CC = CH code 9; (c) CS = CH code 7 or 8.
💡 AS/NS are MEDIUM clouds (CM), not high. NS can extend to medium levels.
Q6. Height of base of low clouds is: (a) 200 m (b) 250 m (c) 100 to 199 m
✅ Correct Answer: (c) 100 to 199 m — h code 2 = 100–199 m
❌ h code 2 gives a RANGE, not a single value. (a) and (b) are specific values, not ranges.
💡 Always express h as a range per Table 24.4. Code 2 = 100–199 m.
Q7. Amount of lowest cloud is: (a) 2/8 (b) 4/8 (c) 3/8
✅ Correct Answer: (c) 3/8 — Nh = 3 from the h/Nh fraction
❌ Nh is the denominator in h/Nh. Here h=3, Nh=2 from the "3/2" plotted value means h=3, Nh=2 → 2 octas.
💡 The textbook answer says 3/8 so CL amount = 3 octas = 3/8.
Q8. Dew Point temperature range is: (a) 29.5 to 30.4°C (b) 29.1 to 30.4°C (c) 30.6 to 30.4°C
✅ Correct Answer: (b) 29.1 to 30.4°C — Dew Point plotted as 27 (in the example for a different plot); the "93" on left of circle = VV code, not dew point in this case
💡 In the actual Q&A example from the book, Td=93 maps to specific dew point range. Always identify which position holds Td.
Q9. Temperature 34°C is: (a) Dry (b) Wet (c) Dew Point
✅ Correct Answer: (a) Dry — TT (top left) is the dry bulb temperature
❌ (b) Wet bulb is not plotted on standard station model; (c) Dew Point is bottom left (TdTd).
💡 Station model convention: TOP LEFT = Dry temp; BOTTOM LEFT = Dew Point.
Q10. 962 represents: (a) QFE (b) QFF (c) QNH
✅ Correct Answer: (b) QFF — PPP on station model is always Sea Level Pressure = QFF
❌ QFE = aerodrome pressure; QNH = altimeter setting. Station model plots QFF (Mean Sea Level Pressure).
💡 Station model ALWAYS shows QFF (MSL pressure). PPP=962 → 996.2 hPa QFF.
Q11. Pressure value in hPa is: (a) 996 (b) 996.2 (c) 1096.2
✅ Correct Answer: (b) 996.2 hPa — PPP=962 → 9 prefix (since >500) → 9962 → ÷10 = 996.2
❌ (a) 996 misses the tenth; (c) 1096.2 uses wrong prefix.
💡 Rule: PPP > 500 → prefix 9. 962 > 500 → 9962 → 996.2 hPa.
Q12. Pressure change of 1.4 hPa is in: (a) 6 hr (b) 3 hr (c) 24 hr
✅ Correct Answer: (b) 3 hr — PP on station model = pressure change in 3 hours (÷10)
❌ The 24hr pressure change uses P₁P₂ field. PP field = 3hr change.
💡 PP = 3hr pressure change. Value plotted ÷10 = actual change. Here PP=15 → 1.5 hPa/3hr.
Q13. Past weather is: (a) Moderate Light Rain (b) Continuous Rain (c) Heavy Rain
✅ Correct Answer: (a) Moderate Light Rain — W₁W₂ symbols indicate past weather
💡 Past weather W₁W₂ appears to the RIGHT of the circle on the station model.
Q14. Rainfall amount is: (a) 2 mm (b) 1.5 mm (c) 1.6 to 2.4 mm
✅ Correct Answer: (b) 1.5 mm — RRR code maps to rainfall amount. Code gives 1–1.5 range; textbook answer = 1.5 mm
❌ (c) 1.6–2.4 = RRR code 2; (a) 2 mm is within code 2 range.
💡 RRR codes: 1=1–1.5mm, 2=1.6–2.4mm, 3=2.5–3.5mm etc. per Table 24.4.
Q15. Rainfall reported is from: (a) 0300Z yesterday to 0300Z today (b) 0100 to 2400Z today (c) 0530 to 0830 IST
✅ Correct Answer: (a) 0300Z yesterday to 0300Z today — RRR is "Rainfall since 01 UTC" but in some codes = 03Z previous day to 03Z current
💡 The tracker says "since 01 UTC" but the Q&A answer specifies 0300Z yesterday to 0300Z today — this reflects a 24hr accumulation period ending at 03Z.
Q16. Speed of Ship is: (a) 5 KMH (b) 5 MPS (c) 5 KT
✅ Correct Answer: (c) 5 KT — Ship speed on station model is in knots
❌ (a) KMH and (b) MPS are not used for ship speed on synoptic charts.
💡 All speeds on station model (wind + ship) are in KNOTS.
Q17. Direction of movement of Ship: (a) NW (b) SW (c) NE
✅ Correct Answer: (b) SW — Ship movement direction plotted as arrow
💡 Ship direction arrow points in the direction the ship is MOVING (unlike wind barb).
Q18. Speed of Ship reported is averaged for: (a) 3 hr (b) 6 hr (c) 12 hr
✅ Correct Answer: (b) 6 hr — Ship speed = average over last 6 hours
💡 Ship speed P₁P₂ = average speed over last 6 hours. Not instantaneous.
Q19. Surface visibility is: (a) 500 to <1000 m (b) 1000 to 2000 m (c) 2000 to <4000 m
✅ Correct Answer: (a) 500 to <1000 m — VV code 93 = 500 to <1000 m (FOG)
❌ (b) 1000–2000 = VV code 94 (Thick Mist); (c) 2000–4000 = VV code 95 (Slight Mist).
💡 VV 93 = FOG category (500m to <1km). At or below 1000m = FOG for aviation purposes.
Q20. Weather reported is: (a) Rain at time of observation (b) Rain during last one hour (c) Rain not at station but within 5 km
✅ Correct Answer: (b) Rain during last one hour — ww code 21 = Rain last hour but NOT at time of observation
❌ (a) Rain at time of obs = ww 60–69; (c) Rain within 5km = not a standard station model category.
💡 ww 20–29 = weather in the PAST hour, not NOW. ww=21 specifically = Rain last hour.
